Notifications are summarized per database. The first card lists active PID pairs, updates are sent only when the lock set or lock details change, and one final card is sent when all tracked locks clear. Long-running manual queries
Checks active queries from tools such as DBeaver or TablePlus. Each PID/query execution is notified once after the threshold; it will not repeat while unchanged. Query changes or a new execution create a new alert.
Use comma-separated PostgreSQL usernames for application accounts. The dashboard control connection is always excluded automatically.
Weekly CSV report
The embedded monitor sends one report per week through the same Teams webhook. Times are IST.
Recommended in production. It lets Teams/Power Automate download the full report securely for seven days, even when SQL text is too large for an inline webhook payload.
